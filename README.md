# Excel Records Manager

Browser-based Excel / CSV records manager. Import, search, filter, edit, and export — **data never leaves your browser**.

**Live:** https://srdesignerwiseneosco-max.github.io/excel-records-manager/  
**Mirror:** https://raw.githack.com/srdesignerwiseneosco-max/excel-records-manager/main/index.html

## Features
- Import `.xlsx` / `.xls` / `.csv` (multi-sheet picker)
- Search, per-column filters, sort, pagination
- Add / edit / delete records (modal + inline double-click)
- Bulk select & delete, duplicate highlight
- Add / rename / delete columns, undo
- Auto-save (localStorage + IndexedDB)
- Export `.xlsx` / `.csv`, print
- Dashboard: counts, sum & average for numeric columns
- Dark / light theme, mobile-friendly, blank sheet starter
- English UI with short Hindi hints

Open `index.html` locally or use the live link. SheetJS is loaded from CDN (local `xlsx.full.min.js` fallback included).
